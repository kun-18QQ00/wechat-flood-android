# 微信刷屏助手 Android 版 v3.0

一款基于 Kivy 框架的安卓刷屏工具，支持自动复制消息到剪贴板，方便快速发送。

## ✨ 功能特性

### 基础功能
- 📝 **多行消息输入** - 每行一条，支持批量
- 🔄 **多种发送模式** - 顺序、随机、单条
- ⏱️ **速度可调** - 0.1秒到5秒间隔
- ⏸️ **暂停/恢复** - 随时控制
- 🎯 **批量限制** - 设置发送总数
- ⏰ **定时停止** - 自动停止功能

### v3.0 新增
- 🌙 **深色模式** - 保护眼睛
- 📚 **消息历史** - 自动保存，快速复用
- 📦 **预设消息** - 内置多种常用模板
- 📱 **自动打开微信** - 一键启动
- 📳 **振动反馈** - 操作提示
- 💡 **使用引导** - 首次启动显示说明

## 📲 下载安装

### 方式一：下载预编译 APK
1. 前往 [Releases](../../releases) 页面
2. 下载最新版本的 .apk 文件
3. 在手机上安装（需要允许安装未知来源应用）

### 方式二：自行构建
`ash
# 安装依赖
pip install buildozer cython

# 构建 debug 版本
buildozer android debug

# 构建 release 版本（需要签名配置）
buildozer android release
`

## 🚀 使用说明

1. **输入消息**：在消息框中输入内容，每行一条
2. **选择模式**：
   - 顺序：按顺序循环发送
   - 随机：随机选择消息
   - 单条：只发第一条
3. **调整设置**：
   - 间隔：控制发送速度
   - 批量：限制发送总数
   - 定时：设置自动停止时间
4. **开始发送**：点击「开始」按钮
5. **切换到微信**：手动粘贴或使用自动打开功能

## ⚠️ 注意事项

1. **权限要求**：
   - 存储权限：用于保存历史记录
   - 振动权限：用于操作反馈

2. **使用限制**：
   - 本工具仅复制消息到剪贴板
   - 需要手动切换到微信粘贴发送
   - 请遵守微信使用规范

3. **兼容性**：
   - 支持 Android 5.0 (API 21) 及以上
   - 支持 ARM 和 ARM64 架构

## 🔧 技术栈

- **Kivy** - 跨平台 UI 框架
